# ハンバーガー店のHPサイト

架空のハンバーガー店「サンタモニカ・バーガー(仮名)」のデザイン画像（ChatGPT で生成）から、HTML / CSS でコーディングした見本です（6ページ）。

- 公開ページ: https://shingo-portfolio.github.io/santamonica-burger/
- ページ: `index.html`（トップ）, `menu.html`（メニュー）, `concept.html`（こだわり）, `about.html`（お店について）, `access.html`（アクセス）, `reserve.html`（ご予約）
- ご予約は、送ると同じページで完了の表示に切り替わります（`js/reserve.js`）。入力した内容はどこにも送りません
- 色・文字・余白などの値は `css/tokens.css` にまとめ、`css/components.css` はその値だけを使っています
- パソコンとスマホの幅に対応しています
- デザイン: `design/`（ページごとの元の画像）
- 仕上がりの画面: `screenshots/`（幅 1440px と 375px）
